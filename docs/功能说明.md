# Selected 功能说明

本文档描述应用的当前功能与主要口径。

> 本应用是信号分析与决策辅助工具，不构成投资建议，也不含下单交易功能；买卖由用户在券商端自行执行。

## 一、产品定位

围绕「尾盘买入、次日午前卖出」的短线策略，把一次选股拆成可验证的闭环：

```text
早盘预判 → 盘中验证 → 尾盘三轮选股 → 三轮对比 → 收盘复盘 → 三日迭代
```

设计目标：

- **纪律优先**：宁可少选，不降门槛；红灯日不给买入信号。
- **可复现**：同一份行情快照、同一份参数，得到同一份结果。
- **可解释**：每只股票的分数、加减分和排除理由都落库可查。

## 二、每日节奏

| 时刻 | 任务 | 说明 |
|------|------|------|
| 09:30 | 早盘预判 | 基于昨日选股生成操作窗口、目标价、止损价和仓位建议 |
| 10:00 | 盘中验证 | 对比预判与实际走势，记录偏差 |
| 14:00 | 第一轮选股 | 尾盘扫描 |
| 14:30 | 第二轮选股 | 尾盘扫描 |
| 14:50 | 第三轮选股 | 尾盘扫描（最终轮） |
| 14:50 | 全量判定 | 自选股三层判定 |
| 15:02 | 三轮对比 | 交并集、信号分类、分档 |
| 15:05 | 收盘复盘 | 胜率统计与准确度归因 |
| 15:10 | 板块热度 | 行业板块涨幅、主力净流入、涨跌家数、领涨股 |
| 15:15 | 涨停统计 | 涨停池、连板数、封板时间、炸板次数 |
| 15:25 | 指标快照 | 全市场指标值，供指标筛选使用 |
| 15:30 | 三天迭代 | 趋势洞察与仓位建议 |
| 16:05 | 资金流向 | 全市场主力净额快照 |
| 17:30 | 龙虎榜 | 当日上榜记录与席位明细 |

任务到点触发；超过补跑窗口会记为「未执行」并给出原因。周末和节假日自动跳过。任务时刻随版本固定，不在设置页编辑。

## 三、选股

### 一轮扫描

1. **交易日判断**：非交易日直接返回。
2. **全量行情**：批量拉取报价，校验行情数量和报价日期。
3. **大盘环境**：根据指数涨跌、振幅、涨跌家数、连跌天数给出红黄绿灯；市场状态用于浮动门槛，不改变灯级。
4. **硬性过滤**：价格带、振幅、涨幅、ST/退市/B股、一字板等。
5. **打分**：趋势、形态、资金、分时结构等维度加权，输出每只票的加减分明细。
6. **深度验证**：对候选做更细的指标和形态校验。
7. **档位与预算**：按分数分档，结合当日市场环境给出数量与仓位约束。
8. **落库**：每层结果都落库，选股结果页可逐层查看漏斗。

### 三轮对比

三轮结果按交并集合并，标记「三轮均入选 / 两轮入选 / 单轮入选」，再结合跨轮分数变化给出信号分类和分档。最终候选进入早盘预判。

### 四阶段闭环

| 阶段 | 内容 |
|------|------|
| 早盘预判 | 给出操作窗口、目标价、止损价、仓位建议；红灯日提示空仓 |
| 盘中验证 | 记录预判与实际走势的偏差，更新策略命中率 |
| 收盘复盘 | 按四层口径统计胜率，归因到具体标的和信号 |
| 三日迭代 | 汇总近三日结果，生成趋势洞察和参数调整方向 |

次日真实结果会自动回填，供复盘和调优使用。

## 四、自选与持仓

- **分组管理**：自选股按分组维护，支持拖动调序和跨组移动。
- **三层判定**：综合趋势、位置与量能给出买入 / 观望 / 卖出倾向，结果每日收盘后更新。
- **持仓统计**：录入成本、数量后可看市值、当日盈亏、累计盈亏和持仓占比。
- **价格提醒**：支持涨幅、跌幅、突破、跌破等条件，可选单次或每日重复。
- **次日区间估计**：结合波动率和近期振幅给出次日高低区间，仅作参考。

### 持仓口径

- 成本 = 买入均价 × 数量。
- 当日盈亏 = 当前市值 − 昨日收盘持仓市值。
- **当日盈亏率 = 当日盈亏 / 昨日收盘持仓市值**；不是除以原始成本。
- 累计盈亏 = 当前市值 − 持仓成本。
- 现价为 0 或行情缺失时，该标的的派生指标显示为「—」，不按 0 计入汇总。

## 五、收盘数据

- **板块热度**：行业板块当日涨幅、主力净流入、涨跌家数、换手率、领涨股。
- **涨停统计**：涨停池、连板数、封板时间、炸板次数；另算昨日涨停今日表现。
- **资金流向**：全市场主力净额快照。
- **龙虎榜**：当日上榜个股与营业部席位明细。
- **指标快照**：全市场逐只计算趋势、动量、波动率、成交量四类指标，供指标筛选页使用。

这些数据在收盘后由调度任务抓取并落库，也可在对应页面手动刷新。

## 六、参数中心

- **参数版本**：出厂版本 + 用户另存的版本；同一时间只有一个激活版本。
- **单域编辑**：打分规则、过滤链、档位与预算、预判策略、复盘迭代、参数调优分域编辑，保存前可看与当前激活版本的差异。
- **版本对比**：任选两个版本逐项对比。
- **历史重放调优**：用历史样本评估参数改动，结果仅作参考，不自动应用。
- **恢复出厂**：可把出厂版本恢复为随包默认值，不影响用户自建版本。

参数分 13 组、约 70 项；只有参与选股（打分、过滤、档位）的参数进入版本线，指标筛选参数单独维护。

## 七、界面

左侧导航共九个页面，启动时恢复上次停留的页面：

| 页面 | 内容 |
|------|------|
| **看板** | 当日概览：四指数、持仓盈亏、大盘灯、昨日涨停表现、领涨板块、信号分类 |
| **自选** | 分组、持仓盈亏、三层判定、价格提醒、次日区间 |
| **指标筛选** | 多指标 AND 筛选（最多 6 个条件），结果表按条件分列、可排序 |
| **选股结果** | 三轮漏斗、档位明细、ETF 推荐、三轮对比 |
| **早盘预判** | 操作窗口、目标价、止损价、仓位建议 |
| **复盘验证** | 四层胜率、准确度归因、逐标的明细 |
| **历史迭代** | 三日迭代报告、胜率趋势、空仓占比 |
| **板块热度** | 行业板块排行，可按涨幅或主力净流入排序 |
| **参数中心** | 参数版本、单域编辑、版本对比、调优 |

设置是独立的偏好设置窗口（`Cmd+,`），分「显示 / 自动化 / 提醒 / 数据 / 关于」五类。

## 八、数据与备份

- 数据默认存放在 `~/Library/Application Support/Selected`。
- 主库 `selected.sqlite3` 存选股、复盘、自选、参数和收盘数据；`history.sqlite3` 存日 K 缓存。
- 每次打包发版会自动做一次 WAL 一致性快照，归档到备份目录，滚动保留 5 份。
- 恢复时先退出应用，校验归档，再替换数据目录；具体命令见 `scripts/verify_backup.sh` 的说明。

## 九、系统要求与安装

- macOS 26 及以上，仅 Apple Silicon（arm64）。
- 从 Releases 下载 DMG，拖入「应用程序」即可。
- 应用未做 Apple 公证，首次打开需右键「打开」。
- 自动更新每日静默检查一次；发现新版只在侧栏齿轮亮红点，手动检查走应用菜单或「关于」页。

## 十、已知边界

- 策略面向 A 股主板、创业板、科创板，不覆盖北交所。
- 不提供沪深股通（北向）资金数据：官方披露口径已变化，粒度和策略时间尺度不匹配。
- 行情和日 K 依赖公开数据源，高频或批量请求可能触发限流；失败会在「数据源诊断」中留痕。
- 次日区间和参数调优结果都是统计参考，不保证收益。
- 不做读屏无障碍适配；界面按桌面鼠标/键盘操作设计。
